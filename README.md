# Library Management System

## Setup Instructions

### Requirements
- Node.js version 14 or higher

### Steps to Run
1. Unzip the folder
2. Open a terminal inside the `library-app` folder
3. Install dependencies:
   ```
   npm install
   ```
4. Start the server:
   ```
   node server.js
   ```
5. Open your browser and go to:
   ```
   http://localhost:3000
   ```

## Modules & Features

### Maintenance (Admin only)
- **Add Membership** — Register a new member. All fields mandatory. Choose 6 months / 1 year / 2 years (default: 6 months). Membership number is auto-generated.
- **Update Membership** — Look up by membership number. Extend (6 months / 1 year / 2 years, default: 6 months) or cancel membership.
- **Add Book / Movie** — Add a book or movie to the collection. Type defaults to Book. All fields mandatory.
- **Update Book / Movie** — Search by title/author, select using radio button, then edit.
- **User Management** — Create new system users or edit existing ones. Defaults to New User.

### Transactions (Admin + User)
- **Check Book Availability** — At least one search field required. Results show available books with a radio button to select one. Selected book can be directly issued.
- **Issue a Book** — Type-ahead search for book and member. Author auto-populated (non-editable). Issue date cannot be in the past. Return date auto-set to 15 days ahead; can be reduced but not extended beyond 15 days.
- **Return a Book** — Look up by serial number or pick from active issues list. Issue date auto-populated and non-editable. Return date defaults to the originally set due date and is editable. Leads to Fine Payment page on confirm.
- **Fine Payment** — All fields auto-populated. Fine = ₹5 per day overdue. If no fine: confirm completes the return. If fine exists: "Fine Paid" checkbox must be ticked before completing.

### Reports (Admin + User)
- Active Issues
- Master List: Memberships
- Master List: Movies
- Master List: Books
- Overdue Returns
- Pending Issues

## Assumptions Made

1. **"Category of Books"** page in the flowchart = the Home/Dashboard screen shown after login.
2. **Serial Number** for Return Book = the system-generated Issue ID (format: ISS + timestamp), shown on the Issue confirmation screen.
3. **Fine rate** = ₹5 per day overdue (standard assumption since no rate was specified).
4. **Membership number** is auto-generated by the system (MEM001, MEM002, etc.) — not entered by the user.
5. **"Pending Issues Request"** report = all currently issued (not yet returned) books.
6. **"Master List of Movies"** = books in the collection with type = movie.
7. **User Management "existing user"** = edit name, role, password, or active/inactive status of existing system login users.
8. **Check Availability** searches only available (not currently issued) books.
9. The **Return Date on the Return Book form** defaults to the due date set at issue time, and can be changed to an earlier or later date.
10. **Passwords** are hidden (type="password") on all login and user management forms.

## Tech Stack
- **Frontend**: Plain HTML, CSS, JavaScript (no framework)
- **Backend**: Node.js + Express
- **Database**: SQLite via sql.js (no native compilation needed)
- **Auth**: bcryptjs password hashing
